## 4. Issues Discovered & Fixed During Verification

1. **`ChatView.tsx` React #310 Hooks Ordering Crash**
   - Moving `useEffect(() => { setReplyTarget(null) }, [roomId])` above early returns fixed the crash on creating an open channel with no active room selected.
2. **Unconditional `CLAUDE_CODE_PROVIDER_MANAGED_BY_HOST=1` Breaking `isolated-home` Auth**
   - Scoped `CLAUDE_CODE_PROVIDER_MANAGED_BY_HOST=1` and provider env clearing under `if (ctx.agent.providerId)` in `packages/core/src/runtime/environment-isolator.ts`, preserving `cleanEnv` and `CLAUDE_CONFIG_DIR` while restoring authenticated `isolated-home` execution.
3. **`paused` Room State Overwritten by Inbound Messages / MCP Callbacks**
   - Added `allowUnpause` flag (true only in `controlRoom`) plus `AND state != 'paused'` SQL guards across `applyActionsTx`, `reassign`, `deliverWorkDeliveryTx`, `collab_dispatch`, and `collab_reply`.
4. **Tight Prefix Boundary Handling in `parseLeadingMentions`**
   - Refined prefix boundary matching in `packages/core/src/collab/open-channel-strategy.ts`.
5. **Additional Build & Test Fixes**: `z.ZodType<TConfig, z.ZodTypeDef, unknown>` compatibility (`collab.ts`), `ReactElement` import (`WorkspaceDock.tsx`), `20_000ms` git subprocess timeout (`worktree.test.ts`), and `You are seated as **@${name}**` role matching (`open-channel.test.ts`).
