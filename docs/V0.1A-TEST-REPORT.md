## 4. Issues Discovered & Resolved During Verification

1. **Claude Code CLI `2.1.325` Control Handshake Hang (90s timeout)**
   - **Symptom**: Sending a `user` frame directly after spawning `claude` with `--permission-prompt-tool stdio --input-format stream-json --output-format stream-json` yielded no output until timeout.
   - **Root Cause**: Newer Claude Code releases expect a `{ type: 'control_request', request: { subtype: 'initialize' } }` handshake and `control_response(subtype: 'success')` exchange before consuming the first user turn.
   - **Resolution**: Implemented initialize control handshake and fallback control-request responses in `packages/core/src/runtime/claude-driver.ts`.
2. **Windows Non-Git Workspace Hitting Root `C:\.git` and `$Recycle.Bin` Errors**
   - **Symptom**: Switching to the Changes tab inside temp private workspaces walked up to a stray `C:\.git` and threw permission errors scanning `C:\$Recycle.Bin`.
   - **Resolution**: Guarded drive-root `git rev-parse --show-toplevel` matches in `packages/core/src/workspace/git-service.ts` plus safe `try/catch` handling in `packages/web/src/components/WorkspaceDock.tsx`.
3. **1280px Viewport Top-Bar Crowd Wrapping**
   - **Resolution**: Added proper `min-w-0` and `shrink-0` constraints in `packages/web/src/components/ChatView.tsx`.
4. **pnpm 11 Prebuilt Native Dependency Config Change**
   - **Resolution**: Migrated `onlyBuiltDependencies` to `allowBuilds` in `pnpm-workspace.yaml` so `node-pty@1.1.0` prebuilt ConPTY binaries install cleanly.
5. **ConPTY Cold-Start Timing Flakiness in `e2e.test.ts`**
   - **Resolution**: Replaced the fixed `800ms` sleep with deterministic `core1.terminals.subscribe` output matching before triggering the hot restart check.

## 5. Quick Start & Manual Verification

### 5.1 Production Mode
```bash
pnpm start
```
- URL: `http://127.0.0.1:3210`
- Default credentials: `admin` / `admin` (change via **Settings** after sign-in)
- Dev hot-reload mode: `pnpm dev`

### 5.2 Re-Run Automated Checks
```bash
pnpm build
pnpm test
node scripts/smoke.mjs
node --import tsx scripts/verify-claude-live.mjs
```

### 5.3 Suggested Walkthrough
1. Start with `pnpm start` and sign in at `http://127.0.0.1:3210`.
2. Check **Settings -> Environment Diagnostics** (`git` & `claude`) and configure any OpenAI-compatible Model Provider.
3. Register a project directory under **Workspaces** (or rely on private agent workspaces).
4. Create a **Claude Code CLI** or **Builtin** agent under **Agents** and open a room.
5. Inspect live edits, **Git Diff**, and the **Web Terminal** in the right Workspace Dock.
