## 4. Issues Discovered & Resolved

1. **Roundtable Hand Off Triggering `room_members` Unique Index Conflict (`UNIQUE constraint failed: room_members.room_id`)**
   - **Cause**: `idx_room_single_lead` allows at most one active `role_kind = 'lead'` per room, while the initial client mapping used `m.roleKind === 'chair' || idx === 0`, producing two leads whenever the Chair sat at index `> 0`.
   - **Fix**: Resolved a single `leadMember` (`chair ?? lead ?? members[0]`) in [ChatView.tsx](../packages/web/src/components/ChatView.tsx) and assigned `'lead'` iff `m.id === leadMember.id` (aligning `single` handoff to `leadMember` as well). Rebuilt and re-verified end-to-end in the browser.
2. **`Authorization: Bearer` Support on Fastify `/webhooks/generic/:hookId`**
   - **Fix**: Preserved `X-Webhook-Secret` and `?secret=` while adding `Authorization: Bearer <secret>` extraction in [http-server.ts](../packages/core/src/transport/http-server.ts), covered in [inbox.test.ts](../packages/core/src/inbox/inbox.test.ts).
3. **Test Harness Alignment**
   - Aligned `githubWebhookPlugin` `externalKey` assertions (`${event}:${repo}:${number}:${action}`) in [inbox.test.ts](../packages/core/src/inbox/inbox.test.ts) and verified per-seat anonymous masking across 3 seats in [roundtable.test.ts](../packages/core/src/collab/roundtable.test.ts).
4. **Known UI Design Note (non-blocking)**: The Routing Rules form in `InboxView` omits an optional target workspace selector (supported in the RPC API and available in the manual Assign Ticket modal).
